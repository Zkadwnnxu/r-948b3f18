# 影视资源配置维护

目标：只维护公开CMS接口配置，生成MediaHubTV可读sites JSON，不更改软件、不播放或下载媒体、不复制影片库。

文件：catalog.json保存用户23站及官网证据；scripts/update.py检查元数据和生成vod.json/health.json；tests为生成与暂时故障规则的离线回归；工作流每6小时检查并仅更新data分支生成文件。

实施：1. 核对官网和API分类/列表/详情/搜索。2. 实现及离线验证有界读取、有效JSON和连续失败保留规则。3. 用真实元数据运行并用MediaHubTV原解析器校验。4. 发布data分支固定链接、提交维护脚本PR；按用户Git规则由用户审核合并，工作流合并main后才定时生效。

规则：只输出有HLS剧集元数据的CMS接口，搜索单独判断；连续3轮失败后移出默认清单，原始地址保留catalog和health；整体故障时不覆盖上次非空清单。工作流不读媒体URL，不执行资源站提供的代码。公开仓库不含用户文件路径、凭据、软件源码或数据。初始主分支仅GitHub自动README，开发分支从其最新main创建；data只存请求的发布配置及状态，无代码开发。

验收：固定链接不登录能读取JSON；站点key稳定、type1、绝对HTTP(S)api；全部23站均有报告，无效项不冒充可用；远端字节与本地产物一致。元数据检查通过不代表电视实播通过。
